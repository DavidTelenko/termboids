# termboids

Boids flocking simulation in your terminal using Braille characters.

## Install

```bash
go build
```

## Run

```bash
./termboids
```

## Controls

- `c` - cycle color modes (distance/force/none)
- `g` - toggle spatial grid debug view
- `q` - quit

## Config

Edit `config.toml` to customize boid behavior, colors, and keybindings.
